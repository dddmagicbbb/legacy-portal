- `processApproval` 의 남은 6개는 3절의 ⬜(U05·U06·U08·U10·U13·U18) - 결재자·기안자·수신자가 null 인 경우로, 엔티티를 직접 조작해야 만들 수 있어 낮은 우선순위로 남겼다.
- `statusLabel` 의 남은 1개는 리팩토링 후 생긴 null 방어 분기(`"알수없음"`)다.
- 리팩토링으로 줄 번호가 바뀌었으므로 3절의 줄 번호는 1차 기준(`58724c8`)으로 읽는다.
